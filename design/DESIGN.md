# 行测题库 · 移动端设计规范 v1

## 视觉基调
橙红暖色系，贴合应用图标（#F4701E → #E94560 渐变），米白底，大圆角，轻投影。
目标观感：考公刷题 App —— 专业、克制、有温度，不做拟物和花哨动效。

## 设计令牌（tokens.css）
| 令牌 | 值 | 用途 |
|---|---|---|
| --bg1 / --bg2 | #FFF8F3 / #FDEFE6 | 页面底色（竖向渐变） |
| --surface | #FFFFFF | 卡片 |
| --fg / --fg-2 / --fg-muted | #1C1917 / #57534E / #8B8177 | 三级文字 |
| --line | #F2E6DC | 分割线、描边 |
| --brand-1 → --brand-2 | #F4701E → #E94560 | 主渐变（按钮/强调） |
| --ok / --err | #16A34A / #DC2626 | 对/错 |
| --shadow | 0 6px 24px rgba(233,69,96,.10) | 卡片投影 |
| 圆角 | 22 / 16 / 12 | 卡片 / 按钮输入 / 小标签 |

## 布局规范
- 画布：390 × 844（iPhone 14 逻辑像素），状态栏 44px，底部 Tab 74px（含安全区）
- 页面左右边距 18px；卡片内边距 14–16px；卡片间距 10–12px
- 底部 5 Tab：首页 / 题库 / 专练 / 模考 / 我的
- 固定操作区（开始练习、查看答案、交卷）悬浮在 Tab 上方 88px
- 触控目标 ≥ 44px；正文 15–16px，说明文字 11.5–13px

## 页面清单
1. 首页：今日一练渐变卡 + 三项统计 + 三入口 + 最近试卷
2. 题库搜索：搜索框 + 模块筛选 + 结果卡（关键词高亮）
3. 题型专练：模块 chip + 题型 chip + 题量 4 宫格 + 吸底 CTA
4. 做题页：返回/进度/计时 + 进度条 + 材料 + 选项（选中紫框 / 对绿 / 错红）
5. 模拟考试：年份/地区筛选 + 试卷卡（模块题量 + 状态 + 开始/继续）
6. 题型分析：模块环形图 + 年份条形 + 我的正确率
7. 考点图谱：考点卡（题量 + 子考点 chips + 正确率进度条）
8. 错题本：三项统计 + 筛选 + 错题卡（错误次数 + 重做/掌握/移除）
9. 我的：渐变档案卡 + 设置项列表 + 版本信息

## 实施说明
- 落地到 `xingce-app/web`（Next 静态导出）的 Tailwind v4 主题，替换现有 CSS 变量
- 底部 Tab 用固定定位 + `env(safe-area-inset-bottom)`；桌面宽度下居中 390–480px
- 用 ui-design-to-code 走 `codegen-with-auto-review`，每页截图与 `design/out/*.png` 比对，相似度 ≥ 0.9 才通过
